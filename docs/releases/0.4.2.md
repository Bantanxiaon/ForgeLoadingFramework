# Forge Loading Framework 0.4.2

修正 Forge 26.3 播放区域出现内层标题栏和白边的问题，并检查旧版 GLFW 窗口路径。

嵌入前同步 SDL/GLFW 的窗口装饰状态，保留 SDL 的尺寸跟随，移除播放子窗口额外的原生边框。游戏外层的正常标题栏继续保留。

完整工具包中的作者工具和两份游戏 Jar 均为 0.4.2。请替换两份旧 Jar，保留自己的 loading 视频和配置，避免同时安装新旧版本。

本轮完成原生 SDL/GLFW 边框、最大化/还原、缩放与资源清理检查，以及旧版构建和路由接口回归。

新增代码禁止未经授权商业使用，既有 MIT 部分和第三方文件保留各自许可。完整条款随包提供。
