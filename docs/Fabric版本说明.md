# Fabric 版本说明

Fabric 版的独立项目名为 **Fabric Loading Framework**。它与 Forge Loading Framework 分开开发，使用自己的 Mod Jar、配置文件夹和版本号。

目前 Fabric 版已经完成首轮代码及无界面检查，尚未进行 PCL 启动实测，也尚未公开独立 GitHub 仓库或正式下载。此页是版本说明，不是 Fabric 安装包。仓库公开后，Forge 首页的入口会改为直接指向 Fabric 仓库。

Fabric 版使用 fabricloadingframework 作为 Mod ID，配置目录为 fabric_loading；不需要 Forge 版的两个 Jar 或 fml.toml 设置。目标范围为 Minecraft 1.20.1–26.3 的已知正式版本，实际可用组合还需启动验证。

需要 Forge 版，请前往 [Forge Loading Framework](https://github.com/Bantanxiaon/ForgeLoadingFramework)，并在 [Releases](https://github.com/Bantanxiaon/ForgeLoadingFramework/releases) 下载完整工具包。

两个项目的后续新增代码均按非商业许可提供；已存在的 MIT 授权部分保留原有许可。具体范围以各项目 LICENSE 和商业使用说明为准。
