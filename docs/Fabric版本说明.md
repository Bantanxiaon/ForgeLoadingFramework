# Fabric 版本

Fabric 的独立仓库是 [Fabric Loading Framework](https://github.com/Bantanxiaon/FabricLoadingFramework)。源码、配置模板和教程都在该仓库，后续 Fabric 更新也在那里维护。

当前 Fabric 版为 0.1.0-dev 开发版，已经完成首轮代码及无界面检查，尚未进行 PCL 启动实测，也尚未发布经过游戏验证的正式版。

Fabric 与 Forge 分开开发，使用不同的 Mod Jar、配置文件夹和版本号。Fabric 版使用 fabricloadingframework 作为 Mod ID，配置目录为 fabric_loading，不需要 Forge 版的两个 Jar 或 fml.toml 设置。安装前请确认实例实际使用的加载器。

需要 Forge 版，请前往 [Forge Loading Framework](https://github.com/Bantanxiaon/ForgeLoadingFramework)，并在 [Releases](https://github.com/Bantanxiaon/ForgeLoadingFramework/releases) 下载完整工具包。

两个项目的后续新增代码均按非商业许可提供；已存在的 MIT 授权部分保留原有许可。具体范围以各项目 LICENSE 和商业使用说明为准。
